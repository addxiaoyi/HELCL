# 三端图标重绘与界面细节

本轮基于已验提交 `1d147f0090ca04f3c4cad3e9ab4b33bd64981125`，保留现有品牌标识和页面风格，将导航与常用操作整理为共享的 66 种矢量图形。

## 图形与实现

`src/HelL.Design/IconCatalog.cs` 是三端共同的图形源：24 单位画布，1.8 单位描边、圆端点与圆连接。图形涵盖启动、实例、下载、资源、AI、设置、账号、任务、模组、世界、Java、窗口按钮，以及复制、保存、删除、发送、停止、收藏等常用动作。Avalonia 的选中态加粗到 2.25，图标保留同一语义，通过原有前景、背景与文字标明选中状态。

Mobile 和 Avalonia Desktop 使用 `LauncherIcon` 绘制这些路径，移除 Material 图标依赖。WPF 保持现有 `Ui.Glyph` 的 `TextBlock` 返回类型和私用字形调用契约：已映射的字形绘制矢量，动态文字、颜色和字号继续有效；未映射的少量字形沿用字体显示。直接绘制的 AI 常用操作也与共享图形和线宽对齐。

图标为装饰内容，不再单独获取键盘焦点、截获点击或重复提供辅助名称。操作按钮保留完整文字及目标名称；手机保留至少 44 逻辑像素的按钮区域。

## 同步完善的细节

- 手机设置入口在选中后仍是设置图形，标题、提示与辅助名称一致；宽屏账号入口和手机底栏设置入口按各自层级正确选中。
- WPF 主导航与分类栏图标统一到 16px，标题栏按钮统一图标尺寸并验证垂直对齐；动态最大化/还原仍使用对应图形。
- 桌面导航同步选中态，危险操作图标的辅助名称包含具体目标；窗口最大化/还原按钮的名称随状态变化，当前实例副标题垂直居中。
- 桌面链接项目已有的 Noto 中文字体，避免 Linux 缺少系统中文字库时显示方框。字形映射和实际截图分别验证，不以字体名称字符串代替渲染证据。

子任务说明：[WPF](frontend-icons-wpf.md)、[手机](frontend-icons-mobile.md)、[桌面](frontend-icons-desktop.md)。

## 验收边界

图标检查接入原有实际 WPF UI、桌面 `--ui-smoke` 和手机完整 smoke 流程，验证多个尺寸的非空像素、描边边界、动态变化、颜色继承、明暗主题和导航语义；保留此前的草稿、焦点、分页、安全与 200% 字体回归。Android 原生验收必须取得普通与 200% 会话的 `mobile-icons.json`。

构建、单测、失败先行收据、图标图集和原生截图保存在 `TestResults/frontend-icons-20261120/`，以整合后的最终提交及 CI 回执为准。完整非增量 Core 构建仍存在既有平台与过时 API 警告，没有修改警告策略。物理触控、TalkBack/桌面读屏、厂商键盘及不同刘海设备仍待专项实测。未合并、正式发布或部署。
