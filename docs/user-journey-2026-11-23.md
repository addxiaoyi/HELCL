# 从新用户到日常使用的界面验收

本轮从空数据目录打开 Desktop，检查用户能否理解当前状态、找到下一步、保留输入并在失败后恢复。检查覆盖实际控件事件和渲染后的页面，不以构建通过代替使用体验。保持现有无边框和透明度设置。

## 逐步走查

1. 首次进入：已修复。名称输入放到欢迎区，可直接创建并进入版本选择；创建前解释下一步。左侧快捷创建继续保留。
2. 首次任务页：已修复。没有保存的账号时不再生成“恢复账号已完成”的任务；空列表只说明任务何时出现，不显示无对象的复制/展开日志操作。
3. 未创建实例进入安装：已修复。提供创建入口，并说明实例用于存放游戏和存档。内置版本明确标记为常用版本，刷新才获取完整清单。
4. 未安装游戏进入资源中心：已修复。明确可以先浏览，下载与兼容筛选需要目标实例；未搜索时隐藏无意义分页。导航背景即时跟随当前页。
5. 设置页：复查了深浅主题、透明度选项及现有草稿保护；本轮未改变这些偏好。
6. AI 连接填写错误：已修复。字段有可见标签，错误显示在表单旁；验证失败保留输入，不创建后台失败任务。本地 Ollama 的准备条件及保存与实际请求的区别明确说明。
7. 创建实例后：已验证。欢迎区创建后进入该实例的安装页；离开再返回保留名称草稿，已有实例仍可从工作台开始安装。
8. 小窗口安装：已修复。版本搜索与分类分行，安装按钮固定在可见底部；完整目录与计划留在安装确认中，避免长路径挤出主操作。
9. 模组空列表：确认有“暂无本地文件”和浏览/导入入口。本轮未认证真实模组兼容性或游戏内加载。
10. 存档空列表：确认说明世界会在游戏创建后出现，日志缺失也有说明。本轮未执行真实游戏或世界恢复。
11. AI 建议和日志预览：已修复。点击建议只追加草稿，不立即发送；无日志建议与成功读取日志均保留已有问题，日志发送前仍需确认。更换云端服务地址后必须填写新服务密钥；仅同一地址可留空保留密钥。
12. Mobile 连接失败及横屏：已修复同类密钥复用；设置期间收起聊天输入区但保留其内容，提供“返回对话”。错误在布局后滚动入视口，当前状态明确未保存，避免旧成功信息误导。回归检查错误和保存按钮均位于可见滚动区。
